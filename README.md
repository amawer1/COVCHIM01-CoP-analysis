# COVCHIM01-CoP-analysis

Analysis of baseline and post inoculation immunology data and its association with virology data in the COVCHIM01 SARS-CoV-2 Controlled Human Infection Model.



i) `Baseline immune markers heatmap and nasal serum correlation plot.r`: An R script for generating pairwise correlation between baseline immune markers using hierarchical clustered heatmaps across specific comparable groups of interest.



ii) `Repeated EN.r`: An R script for performing repeated Elastic Net feature selection analysis of important immune markers as well as Firth's penalised regression of quantifiable viral shedding based on the best selected markers and additional descriptive summary plots.



iii) `Volcano plot and forest plot.r` An R script for generating additional Volcano and forest plots based on estimated odds ratios following immune marker-specific logistic regression (profile likelihood CIs)
